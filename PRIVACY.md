# Privacy Policy

Effective date: August 20, 2026

Canvas Design is a skills-only plugin published by Eng. Khaled Alimawi. It contains instructions and static assets and does not operate an external server, connector, account system, analytics service, or independent user database.

## Information handled

The plugin may guide ChatGPT or Codex to work with text, images, logos, brand assets, and design requirements that a user chooses to provide. The publisher does not independently receive, collect, sell, or store that content through this plugin.

User content and generated outputs are handled by the ChatGPT or Codex product in which the plugin runs and remain subject to OpenAI's applicable terms and privacy policies. If the host product uses web search, image generation, file processing, or another built-in capability while following the skill, that capability is governed by its own product controls and policies.

## External services

Canvas Design does not include an MCP server or third-party connector. It does not request external account credentials and does not transmit user content to a publisher-operated service.

## User choices

Do not provide confidential, regulated, or third-party personal information unless you are authorized to use it and the active ChatGPT or Codex environment is appropriate for that information.

## Changes

Material changes to this policy will be published in this repository with a revised effective date.

## Contact

For privacy questions, open a private-safe support request or public issue only if it contains no confidential information: https://github.com/khaledyo1/canvas-design-plugin/issues
