# Support

For installation problems, unexpected behavior, or design-workflow feedback, open an issue:

https://github.com/khaledyo1/canvas-design-plugin/issues

Include:

- A short description of the problem
- The prompt or workflow that triggered it, with confidential information removed
- The ChatGPT or Codex surface you used
- The expected and actual behavior

Do not post passwords, API keys, private documents, personal identifiers, unpublished brand assets, or other confidential information in a public issue.
