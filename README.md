# Canvas Design

Canvas Design is a skills-only plugin for ChatGPT and Codex that helps users create and refine polished static visual designs.

It supports posters, social-media graphics, advertisements, covers, flyers, editorial artwork, Arabic and right-to-left typography, exact supplied logos and copy, responsive variants, and export-ready PNG or PDF workflows.

## Use

After installing the plugin, start a new chat and invoke:

`@canvas-design`

Example:

> Use @canvas-design to create an Arabic Instagram poster from my brief, preserve my supplied logo exactly, and deliver a polished PNG.

## Package type

- Skills only
- No MCP server
- No external connector
- No separate authentication

The source package is public in this repository. A universal Plugins Directory listing requires separate review and approval by OpenAI.
